# 📊 Customer Behavior Analysis Dashboard

## 📌 Project Overview

This project analyzes customer shopping behavior to uncover patterns in purchasing habits, subscription preferences, product interests, and customer demographics. The objective is to transform raw customer data into actionable business insights using Python, SQL, and Power BI.

The project follows an end-to-end data analytics workflow, including data cleaning, exploratory data analysis, SQL-based business analysis, dashboard development, and business recommendations.

---

## 🎯 Objectives

* Analyze customer purchasing behavior and preferences.
* Identify trends across product categories and demographics.
* Measure subscription adoption and customer engagement.
* Generate insights to support data-driven business decisions.
* Build an interactive dashboard for stakeholder reporting.

---

## 🛠️ Tools & Technologies

* **Python** (Pandas, NumPy, Matplotlib)
* **SQL** (PostgreSQL/MySQL)
* **Power BI**
* **Microsoft Excel**
* **Jupyter Notebook**

---

## 📂 Project Workflow

### 1. Data Collection & Cleaning

* Imported customer shopping behavior dataset.
* Handled missing values and data inconsistencies.
* Prepared data for analysis and visualization.

### 2. Exploratory Data Analysis (EDA)

* Analyzed customer demographics.
* Studied purchase patterns and spending behavior.
* Identified key trends and customer segments.

### 3. SQL Analysis

* Created database tables and imported cleaned data.
* Wrote SQL queries to answer business questions.
* Generated insights related to subscriptions, purchases, and customer behavior.

### 4. Dashboard Development

Built an interactive Power BI dashboard containing:

* Total Customers
* Average Purchase Amount
* Average Review Rating
* Subscription Status Analysis
* Product Category Performance
* Customer Demographic Insights
* Purchase Trend Analysis

### 5. Business Recommendations

* Improve marketing efforts for high-value customer segments.
* Increase subscription adoption through targeted campaigns.
* Focus inventory planning on top-performing product categories.
* Enhance customer engagement strategies based on purchasing patterns.

---

## 📈 Key Insights

* A majority of customers are non-subscribers, indicating opportunities for subscription growth.
* Certain product categories contribute significantly more revenue than others.
* Customer demographics influence purchasing behavior and spending patterns.
* Review ratings help identify customer satisfaction trends.
